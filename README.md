# Bangla Manga — Mihon Extension Repository

An independent Mihon extension repository for **Bangla Manga**.

Browse and read Bangla manga directly through the Mihon app using this extension.

## Installation

1. Open Mihon.
2. Go to **More → Settings → Browse → Extension repos**.
3. Select **Add**.
4. Enter the repository URL:

   ```text
   https://raw.githubusercontent.com/hello-hmemon/banglamanga-repo/main/repo.json
   ```

5. Save the repository and refresh the Extensions page.
6. Find **Bangla Manga** and install it.
7. If prompted, verify and trust the repository signing key.

## Suwayomi Installation

1. Open the Suwayomi WebUI.
2. Go to Browse > Extensions > Extension repositories.
3. Add this repository index URL:

   ```text
   https://raw.githubusercontent.com/hello-hmemon/banglamanga-repo/main/index.pb
   ```

4. Save the repository and refresh the Extensions page.
5. Find **Bangla Manga** and install it.
